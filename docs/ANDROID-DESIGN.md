# starwallpaper：Android 原生版设计基线

状态：原生 App 与已签名 APK 已实现。Android 16 / API 36 与 Android 17 / API 37 模拟器已完成安装及图形回归；Android 17 还验证了系统动态壁纸应用。厂商真机、AOD 和长期耗电尚待验证。

## 体验

产品只围绕一件事：点亮屏幕时，看见这个时刻、这个位置的星空。

视觉采用深蓝近黑底、接近恒星本色的星点和暖白时钟。界面默认隐藏星座连线，降低学习和视觉负担；亮星名称为可选。银河以真实银道定位，增强亮部与暗云，避免把所有星点统一放大成装饰灯。

预览已有传统指针与纵排数字时钟。原生版用同一星空引擎绘制两种时钟；所有数字按用户选择的当地时区显示，天文计算一律使用 UTC。

界面显示独立提供“标准版 / 精简版”，两种时钟均可使用。精简版的壁纸绘制层只显示时间、日期和星空，不绘制地点、方位、坐标、文案、亮星名称或星座名称；预览中的模拟状态栏和底部快捷图标也一并隐藏。开启任一文字标注时自动切到标准版。设置页始终保留完整控制，界面模式随用户偏好保存。原生系统自带的状态栏、解锁控件等仍由系统管理，不将网页预览中的隐藏效果视为系统接口能力。

## Android 16+ 平台

- Android 17 包的最低/编译/目标级别均为 API 37；Android 16 独立包的三者均为 API 36。Gradle 工程保持 Android 17 默认配置，Android 16 包由单独脚本用官方 SDK 36 生成。未来 Android 大版本需要回归验证，不能预先保证零适配。
- Java 原生控件设置界面与 `WallpaperService.Engine` 分离；设置通过 SharedPreferences 在本机持久化。没有 WebView 和第三方运行依赖。
- 动态壁纸引擎通过 `SurfaceHolder`、独立 EGL 线程与 OpenGL ES 3.0 绘制；设置和全屏预览共用同一套原生渲染器。
- 通过系统动态壁纸预览入口让用户应用。锁屏、桌面或两者的可选项由系统壁纸选择器与厂商实现决定。
- 使用 `getWallpaperFlags()` / `onWallpaperFlagsChanged()` 区分系统分配给引擎的目标，不将普通 Activity 伪装为锁屏。

## 系统时钟兼容

普通动态壁纸在系统锁屏内容之后绘制。它不能通过 WallpaperService 的公开接口任意删除系统时钟、通知、安全解锁界面。

本次预览展示的是壁纸内绘制时钟，为了评审视觉没有额外叠加一个厂商系统时钟。因此不能将此预览理解为所有 Android 手机安装后都会自动得到完全一致的锁屏。

原生版提供下列兼容选项：

1. 星空背景模式：选择“使用系统时钟”，壁纸不再自绘时间和日期。
2. 自绘时钟模式：用户的系统若提供隐藏或缩小系统时钟选项，可按该机型能力启用指针或数字样式。
3. 可调布局：通过“时钟位置”调整自绘时钟高度。桌面默认不绘制自定义时钟，可单独开启。

不能承诺用悬浮窗、无障碍或常驻全屏 Activity 绕过安全锁屏。开发验收应至少包含 Pixel 与用户实际目标机型；锁屏仅应用、AOD、通知展开、横竖屏与系统缩放均需检查。

## 时间、位置与视角

星空映射链路为：星表历元/分点 → 当前时刻坐标 → 当地恒星时 → 地平坐标 → 相机朝向/仰角 → 等距鱼眼屏幕投影。明确以对角线定义 120°–180° FOV，避免竖屏把 180°误解释为水平视场。

设置页直接呈现八方位与天顶选择；自定义支持 0–359° 方位角、0–90° 仰角。选择方位保留当前仰角；从天顶切回方位时使用 45° 仰角，避免在天顶只旋转画面却没有转向的误解。视角与星图参数一起持久保存；银河构图作为独立快捷操作。以上交互已接入效果预览，原生设置页沿用该规则。

时间来自系统 UTC 时钟；显示使用系统时区或手动时区，监听日期、时间和时区变更。真实位置以经纬度为准，城市文字只是标签，不影响星图计算。

定位权限方案：

- 首次主动开启“跟随位置”时请求前台定位，优先满足纬度/经度精度需求；不为壁纸索取通讯录或存储权限。
- 使用最近有效坐标，允许手动位置与离线使用。
- 如果要求 App 关闭、用户旅行时仍自动更新位置，需要单独设计并验证后台定位授权、系统限制和厂商电池策略。不能以仅有前台权限就承诺持续后台跟踪。
- 定位计算在设备上进行；默认不上传用户地址、经纬度或位置历史。
- 朝向可手动指定。后续可选传感器交互，但默认保持构图稳定，不持续陀螺仪轮询。

## 星表与银河

安卓与会话预览使用同一份 HYG v4.1 数据，共 115,570 颗恒星。由 `data/catalogue.b64` 原样复制到 Android 资产，坐标、星等、色指数和排序均逐字节一致。记录为 RA uint16、Dec int16、星等 uint8、色指数 uint8，每条 6 字节；3–11 等切点逐项验证，数据许可为 CC BY-SA 4.0。暗星端不完备，不用于精密测量。

原生银河采用银道约束下的程序化艺术纹理，使用与恒星相同的坐标系；光晕与暗云独立调整。纹理低频更新并缓存到 GPU，未使用真实尘埃观测图。后续若替换摄影纹理，需要核验再分发许可。

星点闪烁只调亮度：每颗星稳定相位、不同频率，接近地平线增强。星点不漂移、不随机重排，不引入虚构恒星。强度可在 0–200% 调节，也可关闭。

1.1.0 增加独立的“暗星亮度”设置（50%–400%，当前默认 120%）。GPU 和会话预览使用相同的 `smoothstep(5, 8, magnitude)` 权重，在 5–8 等之间平滑过渡至设置增益。5 等及更亮的星权重为零；8 等及更暗的星使用完整增益。只增强渲染亮度，不修改真实星等、显示上限、坐标、点大小或银河背景。原生像素测试验证了 180% / 50% 的增亮 / 调暗，以及仅含 3 等亮星时 100% 与 400% 的像素完全一致。

## 性能与电量

- 星表按紧凑二进制布局保存，GPU VBO 批量绘制，按星等选择条目并在顶点着色器中剔除视锥及地平线以下恒星，避免逐帧逐星分配对象。
- 星空坐标低频更新，GPU 只对少量亮星应用缓慢亮度调制；在时钟可见时按需要更新秒针。
- `onVisibilityChanged(false)`、Surface 销毁、熄屏时停止渲染与传感器订阅，恢复时按真实 UTC 重新计算。
- AOD 默认交由系统；在未验证厂商行为前不承诺 AOD 动画。低电量可关闭闪烁、秒针，改用低频刷新。
- 预设帧率及耗电数字必须通过真机测量后确定，不用网页预览帧率冒充 Android 性能指标。

## 原生验收

已完成：原生数学基准与 453 个投影样本、115,570 颗恒星的二进制数据完整性与每个星等切点、API / 权限清单、Android 16 和 17 模拟器安装启动、GLES 着色器、天空像素、两类时钟、标准 / 精简界面、预览暂停停止绘制；Android 17 上还验证了系统选择器实际应用动态壁纸，以及合成 GPS 的 LocationManager 回调、坐标保存与关闭跟随后使用手动位置。

仍需真机验证：各厂商系统时钟与 AOD、后台定位节电差异、锁屏切换细节、图形内存、耗电和长时间运行。当前版本为 1.2.4；没有以模拟器帧率冒充手机耗电指标。
